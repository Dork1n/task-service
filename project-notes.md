# Project Notes

Название проекта: Task Service.

Цель проекта: создание простого сервиса для управления задачами.

Основные возможности:
- Создание задач.
- Просмотр списка задач.
- Просмотр отдельной задачи.
- Изменение задач.
- Удаление задач.

Проект разрабатывается в рамках учебной контрольной точки по DevOps.
