# Git Conflict

Во время работы над проектом возник конфликт при слиянии веток main и feature/readme.

Причина конфликта: в обеих ветках была изменена одна и та же строка файла README.md.

Git не смог автоматически объединить изменения.

Конфликт был разрешён вручную: я выбрал нужный вариант текста, удалил служебные маркеры Git и сохранил файл.

После этого создал отдельный коммит с разрешением конфликта.
